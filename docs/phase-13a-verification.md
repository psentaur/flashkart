# Phase 13A local rehearsal

The rehearsal used a fresh single-node kind cluster backed by rootless Podman and a temporary Git mirror reachable from Argo CD. The source baseline was `52d3312`. Argo CD deployed local revision `6aa182c93ea34397fbcbbc281f2ff50e9c30cd10`. The revised bootstrap exited successfully on a second clean kind cluster using the same deployed revision and image digests. The Flink chart sync succeeded and the operator was healthy. Argo CD still reported drift on the operator chart's CRDs.
